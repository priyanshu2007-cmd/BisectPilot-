# Website development with the toolkit

Entry point: `skills/website-builder/SKILL.md`. Typical stack of skills (installed with `--set core,web`):

| Stage | Use |
|---|---|
| Spec | superpowers `brainstorming`, `writing-plans` (`--set process`) |
| Design direction | `impeccable`, `design-taste-frontend` (taste-skill); animation: emilkowalski-skills |
| Components | project components -> shadcn registries -> `repositories/reference-libraries/awesome-shadcn-ui/README.md` |
| React/Next quality | `vercel-react-best-practices`, `vercel-composition-patterns`, `vercel-react-view-transitions` |
| Review (a11y, UX) | `web-design-guidelines` |
| Docs | Context7 (`find-docs`) |
| Verify | `testing-and-verification`, `browser-automation` |
| Ship | `security-review`, `deploy-to-vercel` (needs your explicit approval) |

Pick only what the project needs. A one-section tweak needs none of this.
